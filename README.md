## ▶️ Run an Exercise

1. Install Python 3 if it is not already installed.
2. Clone or download this repository.
3. Open the exercise file in your preferred editor.
4. Run it from your terminal:

```bash
python exercise_01.py
```

Depending on your setup, you may need to use `python3` instead of `python`.

## 🧠 My Practice Method

For each exercise, I aim to:

1. Understand the problem and identify the expected input and output.
2. Plan the logic before writing code.
3. Write and run the solution.
4. Test normal cases and edge cases.
5. Review errors and improve the solution.
